# UZEX 2035 — биржа агентов

> «Не автоматизируйте прошлое. Изобретите будущее UZEX».

**Идея.** В 2035 году люди не торгуют на бирже. У каждого человека и каждой компании есть личный ИИ-агент.
Человек говорит, что ему нужно и какие у него границы. Агенты встречаются на бирже.
Биржа становится тем, чем она и должна быть: **честными правилами, гарантом расчётов и судьёй**.

Терминала, брокера как обязательного посредника и бумаг нет. Человек делает три вещи: формулирует
потребность, подписывает поручение PIN-кодом и фотографирует весовой талон при приёмке.

## Что работает по-настоящему

| Слой | Как устроено |
|---|---|
| **Личный агент** | Claude с инструментами: рынок, прогноз, календарь торгов, поручения, сделки, реестр 500 000 сделок, правовая база. Понимает русский и узбекский, опечатки, голос. Запоминает пользователя (товары, объёмы, регион, решения) и подстраивается под него; память видна и редактируется |
| **Мандат вместо заявки** | Поручение: товар, объём, цена не выше, срок, стратегия. Подписывается ключом Ed25519 пользователя после PIN. Агент не может выйти за его границы |
| **Торговый движок** | Сессии по расписанию, сбор заявок, **единая цена клиринга** (максимум объёма; при избытке предложения цена на старте продавца, при избытке спроса — цена маржинального покупателя). Стратегия `smart`: агент торгуется, начинает около справедливой цены и приближается к лимиту по мере срока |
| **Общие лоты** | Мандаты меньше минимального лота автоматически объединяются в общий лот (5 пекарен = 1 лот) |
| **Клиринг и сейф** | Двойная запись, блокировка задатков, деньги покупателя в сейфе до приёмки, сборы по тарифам UzEx с 01.10.2026 (0,13% / 0,05% / клиринг 0,05%) |
| **Сделка без бумаг** | Договор, счёт-фактура, ТТН, акт приёмки, решение арбитра генерируются из данных сделки и подписываются Ed25519 сторонами и биржей. QR ведёт на публичную проверку подлинности |
| **Цепочка доказательств** | Каждое событие (оплата, погрузка с весом и пломбой, GPS, выгрузка, спор) хешируется вместе с хешем предыдущего. Подделку прошлого видно сразу |
| **Приёмка по фото** | Покупатель фотографирует весовой талон, Claude Vision читает вес нетто. Расхождение больше 0,5% автоматически открывает спор |
| **ИИ-арбитр** | Детерминированные правила определяют, **кто реально платит**: продавец (недогруз), перевозчик (потеря в пути: несовпадение пломбы и GPS-остановка) или никто (в допуске). Деньги распределяются по правилам. Claude пишет мотивировку со ссылками на доказательства, нормы и **реальные дела судов Узбекистана**. Человек утверждает |
| **Щит честности** | На реальном реестре: срывщики задатков, концентрация, зависимость продавца от одного покупателя. Лимиты по ПИНФЛ для дефицитных товаров |
| **Пульт биржи** | Метрики, очередь споров, сценарии для демонстрации, правовая база |

Государственные сервисы (SMS, MyID, оплата картой, самозанятость) — **песочницы** с реальным пользовательским
сценарием: код, селфи с камеры, проверка ПИНФЛ, подтверждение оплаты. Всё, что принадлежит самой бирже
(торги, клиринг, подписи, документы, споры), работает полностью.

## Данные

- **Реальные котировки UZEX**: недельные цены 2024–2026 по 7 товарам с `uzex.uz/Quote/GetDynamics` (1 461 точка),
  включая реальный скачок пропана в сентябре 2026. Арматура: форма из реестра, уровень по реальной котировке.
- **Реестр хакатона**: 500 000 сделок 2022–2026 для аналитики агента и щита честности.
- **Судебная практика**: 4 реальных дела с `publication.sud.uz` (полные тексты актов) и 19 норм
  (ГК, Закон о договорно-правовой базе, Закон о биржах, Правила UzEx).
- **Прогноз**: сезонность по месяцам + сглаженный уровень + затухающий тренд. Точность честно показана
  (средняя ошибка на 4 недели по истории). Рекомендация «покупать или ждать» — совет, решение за человеком.

## Три принципа задания

- **Доступность**: голос на узбекском и русском, вход за 2 минуты (телефон, MyID, PIN), физлица и самозанятые
  с лимитами, общие лоты для маленьких объёмов, ни одного биржевого термина в обязательном пути.
- **Прозрачность**: единая цена с объяснением «почему такая цена», прогноз с точностью, документы с QR-проверкой,
  цепочка доказательств, мотивировка арбитра со ссылками.
- **Безопасность**: мандат с границами и подписью, деньги в сейфе до приёмки, задатки, лимиты по ПИНФЛ,
  щит от срывщиков и перекупщиков, арбитраж по доказательствам, человек утверждает решения.

## Демо за 3 минуты

1. Создать агента: телефон → код → MyID (селфи) → «самозанятый» → агент → пополнение.
2. Голосом: «Мне нужно 8 тонн сахара для цеха до пятницы, сейчас брать или ждать?» Агент показывает цену,
   прогноз с уверенностью, ближайшие торги и готовит поручение. Подписать PIN.
3. На рынке идут торги, агент покупает. Деньги уходят в сейф, документы создаются сами.
4. В пульте включить сценарий «Потеря в пути». Следующая сделка: машина делает остановку вне маршрута, пломба
   не совпадает. На приёмке фото талона: ИИ видит недовес. Арбитр: виноват перевозчик, продавцу оплата за
   отгруженное, покупателю компенсация. Ссылки на реальные дела.
5. Открыть документ по QR: подписи верны, цепочка целостна.

cd app && ../.venv/bin/uvicorn server:app --port 8090
