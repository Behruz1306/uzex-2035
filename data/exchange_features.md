# Что заимствовать у мировых бирж и розничных приложений — UZEX 2035

Собрано 2026-11-07. Формат: **механика** → **почему помогает обычному участнику** → источник.
Пометка «⚠» — данные из СМИ/вторичных источников или устаревшие параметры, сверить перед использованием.

## 1. Московская биржа (MOEX)

### 1.1 Дискретный аукцион вместо остановки торгов (circuit breaker)
- **Механика:** если цена акции отклоняется более чем на 20% от закрытия предыдущего дня и держится так заданное время (10 мин; для бумаг вне Индекса МосБиржи с окт. 2023 — 5 мин), непрерывные торги сменяются серией дискретных аукционов: заявки собираются, затем исполняются по единой цене. С 5.06.2023 — по всем акциям. На валютном рынке с 1.11.2024 — «ценовой коридор»: через 10 с после касания границы стартует аукцион обновления цен.
- **Почему полезно:** защищает человека (и его ИИ-агента) от исполнения по случайной «выбитой» цене в момент паники; для UZEX 2035 — обязательный предохранитель от каскада агентских стоп-заявок.
- **Источники:** https://www.moex.com/a775 , https://www.moex.com/n56397 , https://www.moex.com/n64711 , https://www.moex.com/n74495

### 1.2 Заявка по среднему лимиту (WLIM)
- **Механика:** с 22.09.2025 на рынке акций — лимитная заявка, которая может исполняться частями хуже указанной цены, если средневзвешенная цена всего исполнения остаётся в пределах лимита.
- **Почему полезно:** агент может купить крупную партию через несколько уровней стакана, гарантируя пользователю среднюю цену, а не цену каждой сделки, — понятная пользователю гарантия.
- **Источник:** https://www.moex.com/n93608 ⚠ (точная дата/формулировка по поисковой выдаче)

### 1.3 Центральный контрагент (НКЦ) и гарантийный фонд — «линии защиты»
- **Механика:** НКЦ встаёт между покупателем и продавцом. При дефолте участника убытки покрываются по очереди: обеспечение дефолтера → его взнос в Гарантийный фонд → выделенный капитал НКЦ → взносы добросовестных участников ГФ → капитал ЦК; затем процедура восстановления.
- **Почему полезно:** малый покупатель не должен оценивать надёжность контрагента — риск берёт клиринг. Для UZEX 2035: эскроу/ЦК + гарантийный фонд, куда агенты вносят процент от оборота.
- **Источники:** https://www.moex.com/s1541 , https://www.moex.com/s197

### 1.4 «Финуслуги» — маркетплейс для физлиц
- **Механика:** платформа биржи (в реестре операторов финплатформ Банка России): вклады в разных банках (застрахованы АСВ, лимит отдельно по каждому банку), ОФЗ/«народные облигации», ПИФы, страховки; вход через Госуслуги, пополнение через СБП, для клиента бесплатно, бонус к ставке «+Бонус».
- **Почему полезно:** один вход по госID + сравнение предложений разных поставщиков на одном экране. Аналог для UZEX: вход через MyID/OneID, сравнение лотов разных продавцов, оплата Payme/Click/СМП.
- **Источники:** https://finuslugi.ru/vklady/pravilnyy-vybor-23301 , https://www.moex.com/n55074 , https://t-j.ru/guide/finuslugi/

### 1.5 Индексы
- **Механика:** индекс МосБиржи (IMOEX) — база для триггеров (в фев. 2022 аукцион по всем акциям запускался при отклонении IMOEX >±15%).
- **Почему полезно:** индекс одновременно ориентир «рынок вырос/упал» для новичка и рыночный предохранитель.
- **Источник:** https://www.moex.com/a775 ⚠

## 2. СПбМТСБ / Петербургская биржа (SPIMEX)

### 2.1 Региональные индексы цен на нефтепродукты
- **Механика:** с 2013 г. биржа считает региональные индексы по биржевым сделкам; цены приводятся к единой базисной точке, и, зная ж/д тарифы, можно рассчитать теоретическую цену в любой точке региона.
- **Почему полезно:** фермер/АЗС в регионе видит «справедливую цену с доставкой до себя», а не только цену в Ташкенте. Для UZEX: индекс по вилоятам (хлопок, пшеница, ГСМ, цемент) с поправкой на логистику.
- **Источник:** https://fomag.ru/news/prozrachnost-dlya-nefti ⚠ (2014; актуальную методику смотреть на spimex.com)

### 2.2 Мелкооптовые партии для малых покупателей
- **Механика:** мелкооптовые торги нефтепродуктами (средний лот около 10 т), продажи с независимых нефтебаз; частные сети АЗС покупают напрямую. ФАС/Минэнерго задают минимальные объёмы, которые производители обязаны продавать на бирже.
- **Почему полезно:** малый игрок получает доступ к биржевой цене без посредника-оптовика. Для UZEX: «минимальная партия» на уровне потребности фермера/малого бизнеса + агрегация заявок агентами.
- **Источники:** https://www.vedomosti.ru/finance/articles/2016/06/09/644912-peterburgskaya-tovarno-sirevaya-birzha , https://www.interfax.ru/business/984418 ⚠

### 2.3 Приоритет конечным потребителям (2026)
- **Механика:** с 21.07.2026 биржа ввела обязательный приоритет продаж бензина конечным потребителям (АЗС) на фоне дефицита.
- **Почему полезно:** правило аллокации в кризис защищает реальных потребителей от перекупщиков. Для UZEX: флаг «конечный потребитель» (по ИНН/виду деятельности) с приоритетом при дефиците.
- **Источник:** https://ru.themoscowtimes.com/2026/07/21/peterburgskaya-birzha-s-21-iyulya-pereshla-na-prioritetnye-prodazhi-benzina-dlya-konechnykh-potrebiteley-a201392 ⚠

## 3. CME Group

### 3.1 Микро-контракты
- **Механика:** Micro Gold — 1/10 стандарта (10 тр. унций), расчётная цена равна цене большого контракта; Micro WTI — 100 баррелей (1/10). Micro Agricultural — дневные лимиты как у стандартных, тик вдвое больше, расчёт по цене стандартного контракта. В июне 2026 CME объявила 10-баррельный WTI (1/10 от Micro).
- **Почему полезно:** мелкий производитель хеджирует ровно свой объём, без переплаты за лишний размер. Для UZEX: дробные лоты (0,1 т) с ценой, привязанной к основному контракту.
- **Источники:** https://www.cmegroup.com/articles/faqs/faq-micro-agriculture-futures.html , https://cmegroup.com/education/lessons/micro-gold-and-micro-silver-futures-product-overview.html , https://cmegroup.com/education/articles-and-reports/micro-wti-crude-oil-futures-faq.html , https://www.cmegroup.com/media-room/press-releases/2026/6/11/cme_group_to_expand247tradingforwticrudeoilandgold.html

### 3.2 Динамические дневные лимиты цены (зерновые)
- **Механика:** лимиты по зерну и масличным пересчитываются дважды в год (май и ноябрь) как процент от средней расчётной цены за период наблюдения; при достижении лимита на следующий день он расширяется (expanded). Пример: кукуруза с 03.11.2025 — $0,30/бушель, расширенный $0,45.
- **Почему полезно:** лимит масштабируется с ценой — не слишком узкий при дорогом рынке и не слишком широкий при дешёвом. Для UZEX: лимиты в % от скользящей средней, с авто-расширением.
- **Источники:** https://www.cmegroup.com/content/dam/cmegroup/notices/ser/2025/10/ser-9629.pdf , https://will.illinois.edu/agriculture/note/cme-group-to-automatically-reset-trading-limits-may-1-nov-1

### 3.3 Методика расчётной цены (settlement)
- **Механика:** расчётная цена по зерну — VWAP сделок на Globex в окне 13:14–13:15 CT для ведущего месяца; остальные месяцы — по VWAP календарных спредов; если сделок нет — по bid/ask или изменению соседнего месяца.
- **Почему полезно:** одну минутную сделку трудно «нарисовать», цена прозрачна и воспроизводима — честная база для вариационной маржи и индексов. Для UZEX: публичная формула дневной цены (VWAP последних N минут) и публикация алгоритма.
- **Источники:** https://www.cmegroup.com/trading/agricultural/files/settlement-price-fact-sheet.pdf , https://www.cmegroup.com/tools-information/lookups/advisories/market-regulation/SER-7213.html ⚠ (2014, сверить с текущим Rulebook)

### 3.4 Форварды/фьючерсы для хеджирования производителями
- **Механика:** фермер продаёт фьючерс на объём будущего урожая и фиксирует цену; микро-размеры позволяют хеджировать небольшие объёмы.
- **Почему полезно:** доход фермера предсказуем, проще получить кредит под зафиксированную цену. Для UZEX: «форвард на урожай» с ЦК, агент предлагает хедж при посеве.
- **Источник:** https://www.cmegroup.com/articles/2025/micro-agricultural-futures-how-customers-can-derive-value.html

## 4. NCDEX / Индия

### 4.1 Агрегация через FPO (организации фермеров-производителей)
- **Механика:** FPO становятся членами биржи и торгуют за своих фермеров — объединяют мелкие объёмы в биржевой лот, хеджируют фьючерсами.
- **Почему полезно:** у мелкого фермера нет объёма и знаний; коллективная заявка снимает оба барьера. Для UZEX: «кооператив»/махалля-пул, где ИИ-агенты фермеров сводят заявки в общий лот.
- **Источники:** https://www.sattva.co.in/wp-content/uploads/2023/03/02022023_Perspective_Futures-Trading_FPO_Agriculture.pdf , https://www.business-standard.com/article/pti-stories/ncdex-registers-20-fpos-several-others-in-pipeline-115111700937_1.html ⚠

### 4.2 e-NWR — электронные складские расписки
- **Механика:** с 2018 г. регулятор WDRA выдаёт электронные оборотные складские расписки через два репозитория (NERL от NCDEX и CCRL от CDSL). Под e-NWR дают залоговые кредиты (рекордные ₹3 962 крор в 2023-24 FY); портал e-KUN связывает держателей с банками; через e-NAM можно продать товар со склада, не приезжая на рынок.
- **Почему полезно:** фермер не продаёт урожай сразу по низкой цене — держит на складе, берёт кредит под расписку и продаёт позже. Для UZEX: токенизированная складская расписка как базовый актив + кредит под неё.
- **Источники:** https://wdra.gov.in/documents/d/wdra/2-enwr-enam-process , https://wdra.gov.in/documents/20143/139675979/Bulletin+7+Jan+-+Mar+24.pdf/a6fabeb3-0041-79ef-8acc-557769cbc99f , https://agri.enam.gov.in/enwr-trade , https://wdra.gov.in/documents/d/wdra/bulletin-march26

## 5. Турция — TÜRİB (TMEX) и ELÜS

### 5.1 Электронная складская расписка ELÜS, торгуемая на бирже
- **Механика:** товар сдаётся на лицензированный склад, проходит классификацию в аккредитованной лаборатории, право собственности фиксируется как ELÜS в центральном реестре MKK; ELÜS продаётся, передаётся или закладывается на платформе TÜRİB, расчёты — через Takasbank. Объём в 2025 — ~123,6 млрд TL (9,9 млн т). Госзакупщик зерна TMO закупал через ELÜS. Есть льготные кредиты под ELÜS.
- **Почему полезно:** стандартизированное качество + анонимный электронный рынок = много покупателей, лучшая цена, быстрые деньги для фермера. Для UZEX: цепочка «склад → лаборатория → реестр → биржа → клиринг» как эталон.
- **Источники:** https://ticaret.gov.tr/ic-ticaret/sikca-sorulan-sorular/lisansli-depoculuk-ve-urun-ihtisas-borsasi , https://www.bloomberght.com/turib-te-islem-hacmi-123-milyar-tl-yi-asti-3765247 , https://tarimorman.gov.tr/Haber/5046/Bakan-Pakdemirli-Ureticilerimiz-Elektronik-Urun-Senediyle-5-Milyon-Liraya-Kadar-Sifir-Faizli-Kredi-Kullanabilcek ⚠ (связь бренда TMEX с TÜRİB не подтверждена)

## 6. Розничные приложения

### 6.1 Т-Инвестиции (T-Bank): «Пульс» и автоследование
- **Механика:** «Пульс» — соцсеть внутри брокерского приложения (вкладка «Пульс» → «Каталог»), авторы ведут каналы с идеями; автоследование — подписка на стратегию автора, сделки копируются в счёт подписчика автоматически.
- **Почему полезно:** новичок учится на чужих решениях и видит их обоснование. Риск: стратегии падают вместе с рынком — нужны публичная статистика и предупреждения. Для UZEX: лента рассуждений ИИ-агентов («почему агент купил») + копирование стратегии с лимитом риска.
- **Источники:** https://www.tbank.ru/finance/blog/about-pulse/ , https://www.tbank.ru/otzyyvy/tinkoff-invest/avtosledovanie/ ⚠ (отзывы пользователей)

### 6.2 Тестирование и предупреждения о рисках
- **Механика:** с 1.10.2021 в РФ неквалифицированный инвестор проходит тест перед сделками со сложными инструментами (деривативы, репо, необеспеченные сделки, структурные облигации, ЗПИФ, облигации без рейтинга); попыток — без ограничений. Доля участников среди неквалов снизилась с 23,7% до 9,17%.
- **Почему полезно:** доступ к рискованным продуктам открывается после понимания механики. Для UZEX: короткий тест перед включением агенту фьючерсов/кредитного плеча; уровни доступа.
- **Источники:** https://www.cbr.ru/Content/Document/File/152781/report_20230822.pdf , https://t-j.ru/news/cbr-test-report/

### 6.3 Robinhood: дробные заявки в деньгах и регулярные покупки
- **Механика:** заявки в долларах или в долях акции, округление до цента; регулярные инвестиции (дата начала, частота, сумма, способ оплаты) покупают дробные доли автоматически; неисполненная дробная заявка отменяется через 5 минут.
- **Почему полезно:** «купи на 100 000 сум», а не «купи 0,013 т» — понятно человеку; регулярная покупка усредняет цену. Для UZEX: заявки в сумах, авто-закупка (например, корм/удобрения ежемесячно).
- **Источники:** https://robinhood.com/support/articles/fractional-shares , https://robinhood.com/us/en/support/articles/recurring-investments

### 6.4 Kaspi.kz: суперприложение, оплата в одно касание, раздел «Гид»
- **Механика:** оплата по Kaspi QR мгновенно, с уведомлением продавцу (принимается от клиентов любого банка Казахстана), за рубежом через Alipay+ в 48 странах; комиссия для бизнеса в Kaspi Pay — 0,95%; инструкции — в разделе «Гид».
- **Почему полезно:** одно привычное приложение для оплаты, покупок и инструкций — минимум шагов. Для UZEX: подтверждение сделки агента одним касанием (Telegram-кнопка / QR), встроенный «Гид» для новичков.
- **Источники:** https://guide.kaspi.kz/partner/ru/pos/payments/qr/q2163 , https://bes.media/news/kaspikz-zapustil-oplatu-pokupok-c-qr-kodom-v-48-stranah-sovmestno-s-alipay-8a4f7c/

### 6.5 Ценовые алерты и списки наблюдения
- **Механика:** у Т-Инвестиций, Robinhood и др. есть уведомления о достижении цены и watchlist; официальная справка по алертам в найденных источниках **не подтверждена**.
- **Почему полезно:** человек не сидит у экрана — агент или пуш сообщает о нужной цене. Для UZEX: алерт = триггер, после которого агент предлагает действие через Telegram.
- **Источник:** не найден в официальной справке (⚠ функция широко известна, но в рамках этого поиска не подтверждена документом).

## Шорт-лист для MVP (приоритет)
1. Предохранители: дневной лимит в % от скользящей средней + дискретный аукцион (MOEX/CME).
2. Эскроу/ЦК + гарантийный фонд агентов (НКЦ).
3. Публичная расчётная цена (VWAP-окно) и региональный индекс с логистикой (CME/SPIMEX).
4. Дробные лоты и заявки в сумах + агрегация в пул (CME micro / Robinhood / FPO).
5. Складская расписка как актив + кредит под неё (e-NWR / ELÜS).
6. Лента объяснений агентов, копирование стратегии с лимитом риска, тест перед сложными продуктами (Пульс / ЦБ РФ).
